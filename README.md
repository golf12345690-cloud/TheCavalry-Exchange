# D'CAVALRY Uniform Exchange

Run the website locally:

```powershell
cd C:\Users\GOLFFY\OneDrive\Documents\ChatGPT\Roblox\thecavalry-exchange
npm start
```

Open `http://localhost:3000`.

The server stores user accounts (passwords are scrypt-hashed), authenticated sessions, listings, and each member's listing history in `data/store.json`. That file is intentionally ignored by Git because it contains private user data.
